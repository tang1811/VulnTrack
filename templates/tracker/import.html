รูปแบบไฟล์

คอลัมน์ที่รองรับ (ตัวหนา = จำเป็น)

  • cve_id — เช่น CVE-2024-3094
  • title — ชื่อช่องโหว่
  • severity — ตัวเลข 1-5 (5 = วิกฤต, 4 = สูง, 3 = ปานกลาง, 2 = ต่ำ, 1 = เล็กน้อย) หรือ critical, high, medium, low, info
  • hostname — ชื่อเครื่องที่มีในระบบ
  • cvss_score — 0.0 ถึง 10.0
  • found_at — YYYY-MM-DD (ว่าง = วันนี้)
  • category — รหัสหรือชื่อประเภทช่องโหว่ เช่น rce (ว่างได้)
  • description, solution

ไฟล์ JSON ใช้คีย์เดียวกัน เป็น array ของ object หรือ {"vulnerabilities": [...]}
